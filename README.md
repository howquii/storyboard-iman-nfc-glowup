# Storyboard · «El imán que se queda»

Comercial vertical (9:16, ~30 s) del imán NFC para refrigerador, con el demo de **Glow Up Protein Bar**.

**Ver el storyboard:** abre `index.html` o el enlace de GitHub Pages de este repositorio.

## Contenido
- `index.html` — storyboard completo: 11 planos con boceto, cuadro generado, cámara, luz, SFX y referencias.
- `cuadros/` — cuadros generados con IA (Nano Banana 2.1) para cada plano.
- `bocetos/` — bocetos originales del cuaderno.
- `personaje/` — Lucía, la protagonista, y su hoja de personaje.
- `capturas/` — pantallas reales del flujo de pedido (datos de dirección y teléfono reemplazados por ejemplos).
- `refs/` — referencias de encuadre (Frameset) y de técnica de cámara (EyeCannndy), solo como guía visual.

Audio: solo SFX, sin voz en off.
